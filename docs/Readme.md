# Docs 

This folder simply collects some useful documentations of libraries used in this project (and should contain later useful documentations on the project itself). Each folder corresponds to the name of the module that it documents, described below: 
- `aerosandbox/`: Documentation for the aerosandbox package, cloned as is from [its open source repository](https://github.com/peterdsharpe/AeroSandbox) and contains the source code for [This online book by its main author, Peter D. Sharpe](https://peterdsharpe.github.io/AeroSandbox/)
